# 検証9：4種類の屋根と複数屋根の接合をSolidCraftで作る方式

実施日：2026-11-26。Issue #127。陸屋根・片流れ・切妻・寄棟と、L字の二つの屋根の接合、1階の下屋と2階の屋根を、三つの作り方と三つの接合の仕方でSolidCraftに作った。閉じたボディになるか、面の役割が解決するか、勾配と軒の出を変えて作り直せるか、評価時間を測った。採った方式は次のとおりである。

- 屋根の立体を、軒の外形の角柱から屋根面の平面ごとに切り取って作る。
- 屋根の板は、その立体から鉛直に下げた写しを引いて作る。
- 接する屋根は、屋根ごとの別のボディとして互いに切る。どの形式の組み合わせでも棟の低い屋根を枝とし、接合する屋根は勾配をそろえる。
- 妻壁と片流れの高い側の壁は、その階に載る屋根の下面まで延ばす壁の延長として、壁のボディに含める。

反対役の試しで見つかった四つの誤りと、検証役が見つけた寄棟の枝の規則の抜けを直した後の規則を、もう一度測った。

## 対象と測り方

SolidCraftには屋根を作るコマンドがない。試作は `crates/modeling/src/model/roof_probe/` のテスト専用のモジュールで、住宅データの代わりに、屋根ごとに次の形を持つ。

- 凸な区画の列。区画は、外壁の外面に軒の出を足した軒の外形で、接合する辺では相手の屋根の下まで延ばした外形である。
- 区画ごとの勾配の線の列。屋根面の平面は、その線を鼻隠しの上端の高さで通り、線の左へ勾配で上がる。
- 勾配、板の鉛直の厚さ、期待する面の点と法線。

屋根の板の厚さは、勾配に直角に150 mmとし、鉛直の厚さはそれを勾配の角の余弦で割った値である。基準高さHは屋根の載る階の壁の上端とし、屋根の下面は、軒の側の外壁の外面の線を高さHで通る。軒の出は外壁の外面から板の外面までの水平の距離で、軒とけらばに同じ値を使い、2階の外壁に接する辺には付けない。

屋根の立体Vの作り方を三つ比べた。どの作り方も、Vを板の鉛直の厚さだけ下げた写しUを `solid.move` で作り、VからUを `solid.combine` で引いて板にする。

| 作り方 | 手順 |
| --- | --- |
| P 平面で切る | 区画をXYの角柱として押し出し、勾配の線ごとに、その線を通る傾いた平面にスケッチを置き、平面より上を押し出しで切り取る |
| X 断面の押し出し | 区画の鉛直の断面（切妻は五角形、片流れは台形）を鉛直の平面に描いて区画の幅だけ押し出し、区画の角柱と交わりをとる。寄棟は棟の向きの違う二つの断面と交わりをとる |
| T テーパー | 軒の外形の角柱の上に、側面の勾配を屋根の勾配に合わせた `taper` 付きの押し出しを、棟の高さまで足す。寄棟だけ |

L字では、一覧で先の屋根を主屋根A、後の屋根を枝Bとした。Bは、切妻ならAの棟の線まで、寄棟ならAの向こうの軒まで延ばした。接合の仕方を三つと、負の対照を一つ比べた。

| 接合 | 作るボディ |
| --- | --- |
| J2 屋根ごとに切る | AのボディはV_AからU_AとU_Bを引いたもの。BのボディはV_BからU_A、U_B、V_Aを引いたもの。一覧で先の屋根が重なりを持つ |
| J1 一つに合わせる | V_AとV_Bの和から、U_AとU_Bの和を引いた一つのボディ |
| 負の対照 板を合わせる | V_A−U_AとV_B−U_Bを作ってから合わせる |
| 負の対照 外形をまとめて切る | L字の軒の外形を一つの角柱にして、すべての勾配の線で切る（寄棟） |

場面は次のとおりである。外壁の厚さは200 mm、内壁は120 mmで、平屋の壁は `House::from_layout` で作った本物の壁である。

- 長方形（外壁の外面で10,000×4,550 mm、H=2,400 mm）の陸屋根、片流れ（北へ下る）、切妻（棟は東西）、寄棟。
- L字（長方形に、西の端から北へ4,550×5,450 mmの腕）の切妻どうし（棟は直交）、寄棟どうし、切妻と寄棟、勾配の違う切妻どうし（Aが0.4、Bが0.3）。
- 広い翼のL字（長方形に、西の端から北へ6,000×5,450 mmの翼）の切妻どうし。棟の高い翼を主屋根とし、翼の屋根は南北の両端を妻とする。長方形の腕を枝とし、翼の棟の線（x=3,000 mm）まで延ばした。
- 同じ広い翼のL字の寄棟どうし。翼を主屋根とし、長方形の腕を枝として翼の向こうの軒（西の軒の線）まで延ばした。
- 1階10,000×8,000 mm（H=2,900 mm）の東の4,000 mmを覆う下屋と、2階6,000×8,000 mm（H=5,800 mm）の切妻。2階はまだ住宅データにないので、2階の外壁は角柱で作った。下屋は東へ下る片流れで、2階の外壁に接する西の辺を取り合いとした。

負の対照と診断として、次も作った。

- 急な枝。L字の切妻どうしで、枝Bの勾配をAより0.1大きくし、Aの棟の線まで延ばした。
- 広い寄棟の枝。広い翼のL字の寄棟どうしで、主屋根と枝を入れ替えた。長方形の腕を主屋根とし、棟の高い翼を枝として腕の向こうの軒（南の軒の線）まで延ばした。
- 広い下屋。2階の幅を4,000 mmにし、下屋が東の6,000 mmを覆う。
- 軒の段差。勾配の違う切妻どうしと寄棟どうし（Aが0.4、Bが0.3）で、共有する軒の線のすぐ内側の二つの屋根の上面の高さ。場面の式から求めた。

初めに勾配0.4、軒の出300 mmで作り、次の要求として勾配0.6、軒の出600 mmで作り直した。作り直しは、前のモデルの評価キャッシュを引き継ぐ `Model::build(&house, Some(&previous))` で行った。

各回で次を確かめた。期待値は、どれもCADを使わずに場面のデータから求めた。

- 閉じたボディか、ボディの数、名前。
- 板の体積。鉛直のどの線も板を鉛直の厚さだけ横切るので、勾配が一つなら、体積は鉛直の厚さと軒の外形の面積の積になる。勾配の違う場面は、重なりの部分で上面と下面を別に積分した。
- 屋根一つの表面積。上面と下面がそれぞれ軒の外形の面積を余弦で割った値で、側面が周長と鉛直の厚さの積である。
- 平面の外接矩形が軒の外形と一致するか。作り直しで、軒の出のある辺が300 mmずつ外へ動き、取り合いの辺が動かないか。
- 面の役割。役割ごとの点で `faces_within` がちょうど一つの面に当たり、その面の三角形の法線が期待と合うか。L字では、相手の屋根に隠れる点を除いた。
- 説明できない面。ボディのすべての面が、期待するどれかの平面（屋根面、下面、軒の外形の鉛直面）の上にあるか。
- 上向きの面の法線の傾きと勾配の差。
- 枝の露出。枝のボディの頂点のうち、主屋根の軒の外形の内側にあって、主屋根の上面より上にあるものの数と、上に出た最大の高さ。
- 外周壁を、その階に載る屋根の下面まで延ばした後の、壁の閉じ方、外面の面の数、外面の上端の高さ、屋根の板との交わりの体積。下屋の場面では、1階の壁を下屋の下面まで延ばし、2階の外壁との交わりの体積も測った。下屋と2階の外壁・2階の屋根との交わりの体積も測った。
- 屋根のコマンドの数と、屋根のコマンドだけの評価時間（壁の `Model::build` を除く）。

長さの許容差は0.001 mm（3.4）、体積は軒の外形の面積に0.001 mmを掛けた値、角度は0.001 mmを最も長い辺で割った値の逆正接とした。

測定は、`a88de2f528af4da701b378b278c4356881c195d8`（SolidCraftのupstream `7c0f565e9` を含む）で、Rust 1.99.1のreleaseプロファイルで行った。Mac16,11、macOS 27.2.1、論理CPU12、メモリ24 GiBである。時間は各条件で一回だけ測った値で、ベンチマークとしての精度はない。表を出したときの負荷平均は20.6（論理CPU12）で、ほかの作業のビルドと並んで動いた。同じ場面でも実行ごとに数倍違い、L字の寄棟どうしのPは、これまでの四回の実行の初回で71 ms、128 ms、91 ms、116 msだった。時間は桁の目安としてだけ使う。試作のコードはCodex（gpt-6.2-astra）が書き、担当（Claude Opus）が読んで確かめた。設計の案は二つのOpusが別々に出し、他系統のモデルの判定役は立てなかった。

負の対照と診断は、どれも狙った検査で失敗した。

- 板を合わせると、谷で一方の板が他方の屋根の下へ続いた。体積が、切妻どうしで1.824 m³（作り直しで2.608 m³）、切妻と寄棟で2.736 m³（3.913 m³）、広い翼で2.418 m³（3.333 m³）、広い翼の寄棟どうしで2.401 m³（3.318 m³）多かった。面の点はすべて解決し、説明できない面も0だった。点と平面だけの検査ではこの誤りを見つけられず、体積の検査が要る。
- L字の外形をまとめて切ると、凹んだ角の辺の平面が両方の腕を切り落とした。体積は5.709 m³（期待13.354 m³）、面の点の解決は10/24、説明できない面は2だった。
- 急な枝は、閉じた二つのボディになり、体積も面の点も合った。しかし枝の14の頂点が主屋根の上面より上に出て、最大233.650 mm（作り直しで235.670 mm）だった。延ばした枝の端が、主屋根の棟の上に立つ。
- 広い寄棟の枝は、枝の10の頂点が主屋根の上面より上に出て、最大580.000 mm（作り直しで870.000 mm）だった。ただし、閉じた二つのボディになり、板の体積は翼を主屋根にした場面と0.01 mm³まで同じ（14,630,415,748.02 mm³、作り直しで18,129,595,631.45 mm³）で、面の点も説明できない面の検査も通った。勾配が同じ二つの寄棟は、どちらを枝にしても二つの極大長方形の寄棟の和になり、屋根の形は同じである。翼の棟が腕の棟より高いのはこの形の正しい姿で、入れ替えて変わるのは、重なりをどちらのボディが持つかと、枝の露出の数え方だけである。
- 広い下屋は、勾配0.4・軒の出300 mmでは高い側の上面が5,461.555 mmで、2階の外壁の上端5,800 mmより低かった。勾配0.6・軒の出600 mmでは6,674.929 mmになり、上端を874.929 mm超えた。下屋と2階の屋根の交わりの体積は0で、交わりの検査だけではこれを見つけられない。
- 軒の段差は、切妻どうしでも寄棟どうしでも、Aが2,441.955 mm、Bが2,466.905 mmで、24.950 mmだった。軒の線での板の高さは、基準高さから軒の出と勾配の積を引くので、勾配が違えば同じ線の上で高さが違う。

Tは、長方形でもL字でも、棟の高さちょうどの押し出しを拒んだ。

```text
SMLib extrude: the draft closes the wall at (10300.0000, -300.0000, 2441.5549) before the far end
SMLib extrude: the draft closes the wall at (10600.0000, -600.0000, 2214.9286) before the far end
```

0.001 mm低くすると閉じたボディになり、体積と面の点も合った。ただし棟に幅の狭い水平の面が残り、説明できない面が2、勾配の差が0.3805 rad（勾配0.6では0.5404 rad）になった。これは水平の面の傾き0と勾配の角の差である。Tは切妻と片流れも作れない。L字は両腕の幅が同じ場面だけを試した。

下屋は、2階の4枚の外壁とも、2階の屋根とも、交わりの体積が0.001 mm³以下だった。取り合いの面の点は、作り直しの後もx=6,000 mmの平面で解決した。

外周壁は、延長を結合した後もすべて閉じた一つのボディだった。外面は一つの面のまま、屋根の下面まで延びた。外面の上端の高さは、外面の線での屋根の下面の高さと0.001 mm以内で一致した。どの壁も屋根の板と交わらなかった。下屋の場面では、1階の南と北の壁が下屋の下の部分だけ延び、2階の下の部分は元の高さのままで、2階の外壁と交わらなかった。延長を壁に結合する前の壁と延長は、閉じた二つのボディだった。これは、妻壁を屋根の部品として別のボディにした場合の形である。

テストは場面ごとに分かれ、PとXの両方で長方形の4種類、四つのL字、広い翼の切妻どうしと寄棟どうし、下屋を作り、上の検査を確かめる。負の対照と診断は、狙った検査で失敗することを確かめる。devプロファイルで、テストの本体は並列に15〜45秒かかった（負荷による）。

## 反対役の試し

初めの記録と計画の文は、二つのOpusの反対役に壊させた。反対役は、自分の作業ツリーで試作に場面を足して実行し、四つの誤りを示した。担当がそれぞれのコマンドを実行し直し、同じ出力を確かめた。

- 切妻の枝を相手の棟まで延ばす規則は、枝のほうが急か広いと、延ばした端が棟の上に出る。急な枝で233.650 mm、幅6,000 mmの翼を枝にすると290.000 mm出た。初めの文は条件を書いていなかった。棟の低い屋根を枝とする規則に直し、広い翼の場面と枝の露出の検査を足した。
- 初めの記録は、壁の延長を「すべての屋根のUの和」との交わりとしていた。下屋の場面にこの規則を当てると、1階の壁が2階の屋根の下面まで延び、2階の外壁と1枚につき3.422 m³交わった。その壁の階に載る屋根のUだけを使う規則に直し、下屋の場面で壁の延長を測った。
- 勾配の違う寄棟どうしを、枝を相手の向こうの軒まで延ばして合わせると、軒の高さが24.950 mmずれた。勾配の大きい枝（0.5）は、主屋根の屋根面の上に0.665 m³出た。接合する屋根は勾配をそろえる規則にした。
- 2階が狭いと、下屋の高い側が2階の外壁の上端を超え、2階の屋根の軒の上に出た。交わりの体積は0なので、初めの記録の下屋の検査は通っていた。高い側が上の階の外壁の上端を超える下屋を、確定前に拒む規則にした。

反対役が壊せなかったものもある。

- 寄棟の主屋根に切妻の枝を付けた場面。
- 凹んだL字の領域の片流れ。体積は板の体積の式と合い、外周壁も重ならずに延びた。
- 正方形の寄棟（四角錐）と、一辺が斜めの凸の五角形の寄棟。
- 勾配の小さい枝を相手の棟まで延ばした場面。

## 検証役の試し

PRの検証役（1回目、head `c4d974ca2`）は、寄棟の枝に棟の低い屋根を選ぶ条件が無いことを示した。長方形の腕を主屋根とし、幅6,000 mmの寄棟の翼を枝として腕の向こうの軒まで延ばすと、枝の露出が10頂点、最大580 mm（勾配0.6・軒の出600 mmでは870 mm）になった。主屋根が切妻でも同じだった。

担当は、この並べ方と、翼を主屋根にした並べ方を、どちらも試作に入れて比べた（上の「広い寄棟の枝」と「広い翼のL字 寄棟どうし」）。二つの板の体積は同じで、どちらも閉じた二つのボディになり、ほかの検査も通った。勾配が同じ寄棟どうしでは、翼の棟が腕の棟より高いのが正しい屋根の形で、枝の端が棟の上に立つ切妻の誤りとは違う。それでも、枝の選び方を形式ごとに分けると、#133が組み合わせごとに規則を持つことになり、枝の露出の検査も寄棟では使えない。そこで、棟の低い屋根を枝とする規則を、すべての接合に当てた。

## 採った方式

**作り方はPとする。** PとXはどちらもすべての場面を作れた。Pは、勾配の線一本につき平面で一回切るだけで、形式ごとの断面を持たない。勾配の線がどの向きでも同じ手順で、凸な区画ならどの形でも作れ、反対役の凸の五角形の寄棟も作れた。Xは形式ごとに断面の形を決め、試作では断面を軸に平行な平面に置いた。凸の多角形の寄棟をXで作るには辺の向きごとに断面が要り、Pに交わりを一回足したものになる。コマンドはXのほうが少ないが、時間の差は一回だけの測定では言えない。Tは棟まで届かず、届く手前では棟に細い面が残るので採らない。

**屋根の板は、垂木・野地・屋根材を一体にした一枚の板とする。** 板はVからUを引く一回の操作でできる。次の面がそのときに一度にでき、どの場面でも板の体積が鉛直の厚さと軒の外形の面積の積に一致した。

- 屋根面と軒天。
- 鼻隠し。上端が水平な縁の鉛直面である。
- けらば。上端が傾いた縁の鉛直面である。
- 取り合い。2階の壁に接する面である。

屋根を下面までの塊にすると、けらばの面が軒の出だけ外に出た大きな三角になり、妻壁が外へずれて見えるので採らない。軒天は屋根面と平行に傾き、水平な箱軒は作らない。

**接する屋根は、屋根ごとの別のボディとし、互いに切る（J2）。** J1も同じ形を作れるが、二つの屋根の要素が一つのボディになる。3.5は一つの要素の押し出しを一つのボディとし、色を要素と面の役割に結び付けるので、J1では屋根ごとの色と役割を分けて持てない。#133は、L字を二つの屋根で覆い、屋根を個別に変えることを求めている。どの形式の組み合わせでも、棟の低い屋根を枝とし、棟の高い屋根を主屋根とする。勾配をそろえるので、幅の狭い屋根が枝になる。切妻の枝は相手の棟の線まで、寄棟の枝は相手の向こうの軒まで延ばす。棟の高さが同じなら、どちらを枝にしてもよい。互いに切るときは、棟の高い屋根が重なりを持つ。試作では主屋根を一覧の先に置いたが、一覧の順ではなく棟の高さで決めれば、屋根を足した順に形が左右されない。接合する屋根は勾配をそろえる。勾配の違う切妻どうしはJ2で閉じた二つのボディになったが、軒の高さがずれる。このずれをどう扱うかを決めるまで、勾配の違う接合は受け付けない。

一つの外形から一度に作る方式としては、板を合わせる方法、外形をまとめて切る方法、Tを試した。板を合わせる方法は谷で誤り、外形をまとめて切る方法とTは凹んだ外形を作れないので、どれも採らない。

**別の階の屋根（下屋と2階の屋根）は互いに切らない。** 下屋の高い側は2階の外壁の外面で止め、軒の出を付けない。高い側の上面が上の階の外壁の上端を超える下屋と、上の階の屋根と交わる下屋は、確定前に拒む。

**妻壁と片流れの高い側の壁は、壁の延長として壁のボディに含める。** 屋根の載る階の外周壁のうち、平面形が屋根の軒の外形に重なる壁を、その階に載る屋根の下面まで延ばす。延長は、壁の平面形の角柱と、その階に載る屋根のUの和との交わりで、壁のボディに結合する。外面は一つの面のまま延びるので、外壁に付けた色は妻の三角にも同じ規則で付く。屋根の部品にすると、外壁の色を屋根の側に持たせるか、妻の三角に別の色の表を持たせることになる。壁の高さは軒の高さとして一つだけ保存し、延ばした形は屋根から求める。

**屋根のデータに次の項目を持つ。**

- 載る階。基準高さは保存せず、その階の壁の上端とする。
- 覆う領域。保存せず、階の外形から求める（#128）。切妻と寄棟の領域は凸とし、L字は二つの屋根で覆う。片流れと陸屋根は平面一枚なので、凹んだ領域も作れる。
- 形式（陸屋根・片流れ・切妻・寄棟）。
- 勾配。陸屋根は持たない。
- 向き。片流れは下る向き、切妻は棟の向きを、平面の角度で持つ。寄棟と陸屋根は持たない。#131は一般の長方形と凸の多角形の寄棟を、#143は斜めの壁を扱う。東西南北だけでは回った長方形の切妻を表せない。壁のIDで表すと、壁の分割や削除のたびに付け替えが要る。
- 軒の出。軒とけらばに同じ値を使う。
- 素材。

## 残る課題

- 試作の屋根はどれも一つの長方形の区画で、一つの屋根の中で複数の区画を合わせる手順は試していない。
- 接合する辺の先へ屋根を延ばす長さと、どちらを主屋根にするかは、場面ごとに手で決めた。住宅データから求めるのは、接合の作業（#133）である。
- 勾配の違う屋根の接合で、軒の高さのずれを許すか、勾配をそろえるかは、接合の作業（#133）で決める。
- 壁の色の検査（3.5）は、壁の高さまでの面を期待する。延ばした妻の三角を含めるのは、切妻の作業（#130）である。
- 下屋を拒む条件は、試作では測っただけで、拒む検査は作っていない（#128か#133）。
- 板の体積の期待値は、試作と同じ鉛直の厚さから求めた。勾配に直角150 mmという厚さそのものは、独立には照合していない。
- Tは、両腕の幅が同じL字だけを試した。

## 再実行と証拠

通常の検査は `cargo test -p madori-modeling roof_probe` で実行する。表は `cargo test --release -p madori-modeling roof_probe_table -- --ignored --nocapture` が出力し、上の値は [roof-probe-table.md](evidence/verification-09/roof-probe-table.md) に保存した。表の初めの4行は、広い下屋と軒の段差の診断である。残りの各行は次の欄を持つ。

- 場面、作り方、接合、勾配と軒の出。
- 閉じ方とボディの数。
- 体積と期待値と誤差、表面積と期待値、外接矩形と期待値。
- 面の数、面の点の解決数、説明できない面の数、勾配の差。
- コマンドの数、時間、枝の露出、壁の測定。

反対役の試しの再現のテストは、記録に使った後で反対役の作業ツリーと一緒に消した。直した規則は、上の場面と負の対照として試作に入れてある。
